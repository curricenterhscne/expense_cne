# 참학력 온라인 공동교육과정 수업운영비 신청 시스템

충청남도교육청 중등교육과에서 운영하는 **공동교육과정 수업운영비 신청서 수합 시스템**입니다.

## 업무 흐름

1. 교육청이 학기별 강좌 목록을 확정하여 스프레드시트 `강좌목록` 시트에 붙여넣음
2. 각 강좌 담당 교사가 웹 폼에서 신청서를 작성·제출
3. 제출 즉시 신청서 PDF를 내려받아, **공문으로도 별도 제출** (증빙용)
4. 교육청은 공문 PDF로 증빙을 받고, 온라인 데이터로 집계·교부 처리

> 온라인 제출과 공문 제출이 짝을 이룹니다. 담당자가 `접수상태` 열로 이를 관리합니다.

## 기술 스택

| 계층 | 기술 |
|---|---|
| 프런트엔드 | 순수 HTML + CSS + Vanilla JS (프레임워크·빌드 없음) |
| 호스팅 | GitHub Pages (`docs/` 폴더) |
| 백엔드 | Google Apps Script 웹앱 |
| 데이터 | Google 스프레드시트 |
| GAS 배포 | clasp |
| PDF | 브라우저 인쇄 (`window.print()` + `@media print` CSS) |

> 외부 CDN 의존성이 없습니다. 교육청 네트워크에서 차단 우려 없이 동작합니다.

## 개발 환경 준비

### 1. clasp 설치 및 로그인

```bash
npm i -g @google/clasp
clasp login
```

### 2. GAS 프로젝트 연결

```bash
cd gas
clasp clone <스크립트ID>
```

> `.clasp.json`이 생성됩니다. 이 파일은 스크립트 ID만 포함하므로 커밋 대상입니다.

### 3. 로컬 확인

```bash
cd docs
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다.

> `file://`에서는 GAS 요청이 CORS로 막힐 수 있으니 간이 서버를 사용하세요.

## 배포 절차

### 프런트엔드 (GitHub Pages)

`main` 브랜치에 push하면 자동 반영됩니다.

- Settings → Pages → Source: `main` / `docs`

### GAS 백엔드

```bash
cd gas
clasp push --force
```

push 후 **반드시 아래 순서로 배포**합니다:

1. [Apps Script 편집기](https://script.google.com) 열기 (`clasp open`)
2. 우측 상단 `배포` → **`배포 관리`**
3. 기존 배포의 **연필 아이콘(편집)** 클릭
4. 버전을 **`새 버전`**으로 선택 → `배포`

> **⚠ 절대 `새 배포`를 하지 마세요.** `새 배포`를 하면 `/exec` URL이 바뀌어 교사 안내 링크가 전부 무효화됩니다. 반드시 **기존 배포 편집 → 새 버전**을 선택해야 URL이 유지됩니다.

## 스프레드시트 메뉴

스프레드시트를 열면 `📊 운영비 관리` 메뉴가 나타납니다.

| 메뉴 | 기능 |
|---|---|
| 설정 확인 | 설정 시트 값을 읽어 정상인지 확인 |
| 집계표 새로고침 | 접수상태 = '접수'인 건으로 집계표 시트 생성 |
| 미제출 목록 생성 | 미제출·공문미접수 강좌 목록 시트 생성 |
| 새 학기 시작 | 보관 사본 → 초기화 (학기 종료 시) |

## 다음 학기 운영 절차

1. 스프레드시트 메뉴에서 **`새 학기 시작`** 실행
   - 현재 데이터를 보관 폴더에 사본으로 저장
   - 사본 검증 후 신청내역·집계표·미제출·강좌목록 초기화
   - 접수번호 시퀀스 초기화
2. `설정` 시트에서 학기명·학기코드·신청기간 업데이트
3. `설정` 시트의 접수상태를 `접수`로 변경
4. `강좌목록` 시트에 새 학기 강좌 데이터 붙여넣기
   - 수강인원에 `#N/A` 없는지 확인
   - 강좌코드 중복 없는지 확인
5. 교사에게 신청 링크 안내 (**URL 변경 없음**)
6. 접수 기간 중: `미제출 목록`으로 독촉, 공문 도착 시 `접수상태` 변경
7. 신청 마감 후: `접수상태`를 `마감`으로 변경
8. `집계표 새로고침` 실행 → 교부 처리

> 자세한 운영 절차는 `manual/담당자용.md`를 참고하세요.
