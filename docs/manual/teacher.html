수업운영비 신청서 작성 안내

참학력 온라인 공동교육과정 · 수업 지도교사용

신청 절차

  1. 담당자가 안내한 신청 링크에 접속합니다.
    Chrome 또는 Edge 브라우저를 권장합니다.
  2. 강좌를 선택합니다. 드롭다운에서 본인의 강좌코드를 찾아 선택하면 과목명·소속교·수강인원 등이 표시됩니다.
    2개 이상의 강좌를 담당하는 경우, 강좌별로 각각 신청서를 제출해야 합니다.
    한 강좌 제출 완료 후 → '다시 작성하기' → 다른 강좌 선택 → 다시 제출해 주세요.
    이미 제출한 강좌는 목록에 ✓ 표시가 됩니다. 다시 선택하면 수정 제출할 수 있습니다.
  3. 연락처 뒤 4자리를 입력하고 [확인] 버튼을 누릅니다. 강좌목록에 등록된 교사 연락처의 뒤 4자리와 일치해야 합니다.
  4. 운영비 희망 여부를 선택합니다.
    • "희망합니다" → 소요예산 항목을 입력합니다.
    • "희망하지 않습니다" → 항목 없이 바로 제출 가능합니다.
  5. 소요예산 항목을 입력합니다 (최대 10개). 각 항목에 물품명(예: 마이크로비트 보드, 수평잡이 오뚝이), 산출식, 금액을 적습니다.
    천원 단위로 작성하세요 (백원 이하 절사).
    지원 한도는 수강인원 × 인당 단가이며, 강좌 선택 시 자동 계산됩니다.
  6. 내용을 확인한 뒤 [신청서 제출하기] 버튼을 누릅니다. 확인 대화상자에서 내용을 검토하고 [확인]을 누르면 제출됩니다.
  7. 완료 화면에서 [신청서 PDF 저장] 버튼을 눌러 PDF를 저장합니다.
    인쇄 대화상자가 열리면 대상(Destination)을 'PDF로 저장'으로 선택하고 [저장]을 누르세요. 파일명은 자동으로 「학기코드_수업운영비신청서_강좌코드_교사명」 형태로 설정됩니다.
  8. 저장한 PDF를 공문에 첨부하여 별도 제출합니다.
    온라인 제출과 공문 제출이 모두 완료되어야 접수 처리됩니다.

자주 묻는 질문

잘못 제출했는데 어떻게 수정하나요?
같은 강좌로 다시 접속하여 수정 제출하면 됩니다. 기존 내용이 자동으로 불러와지고, 제출하면 이전 신청을 대체합니다. 접수번호는 변경되지 않습니다.
연락처 뒤 4자리가 맞지 않다고 나옵니다.
강좌목록에 등록된 연락처와 다를 수 있습니다. 5회 실패하면 10분간 잠기니, 맞지 않으면 담당 장학사(☎ 041-640-7221)에게 등록된 연락처를 확인해 주세요.
PDF 저장 버튼을 눌렀는데 인쇄가 되어 버립니다.
인쇄 대화상자에서 대상이 프린터로 되어 있으면 종이로 출력됩니다. 대상을 'PDF로 저장' (Chrome) 또는 'Microsoft Print to PDF' (Edge)로 변경해 주세요.
운영비를 신청하지 않아도 제출해야 하나요?
필수가 아닙니다. 운영비가 필요하지 않으면 제출하지 않아도 됩니다. 다만, 신청하지 않을 경우에도 "희망하지 않습니다"로 제출해 주시면 담당자가 미제출 독촉을 하지 않아 양측 모두 편리합니다.
한도를 초과하는 금액이 필요합니다 (실험실습 재료 등).
실험실습 재료(키트 등)로 인해 한도 초과가 필요한 경우, 별도 문의해 주세요.(☎ 041-640-7221,7224)에게
2개 이상 강좌를 담당합니다. 한 번에 신청할 수 있나요?
아닙니다. 강좌별로 각각 제출해야 합니다. 한 강좌를 제출한 뒤 완료 화면에서 '다시 작성하기'를 누르고, 다른 강좌를 선택하여 다시 신청서를 작성·제출해 주세요. 공문도 강좌별 PDF를 각각 첨부합니다.
학생 간식비도 신청할 수 있나요?
오프라인 수업 활동이 있을 경우에만 학생 1인당 6,000원 한도로 사용 가능합니다.
