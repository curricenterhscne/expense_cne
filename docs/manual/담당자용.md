# 수업운영비 신청 시스템 — 담당자 운영 매뉴얼

## 1. 학기 시작 전 준비

### 1-1. 설정 시트 갱신

스프레드시트의 `설정` 시트에서 다음 값을 확인·수정합니다.

| 키 | 설명 | 예시 |
|---|---|---|
| 학기명 | 헤더·집계표 제목에 표시 | `2026학년도 2학기` |
| 과정명 | 교육과정 이름 | `참학력 온라인 공동교육과정` |
| 거점학교명 | 거점학교 | `충남온라인학교` |
| 학기코드 | PDF 파일명·보관사본 이름에 사용 | `26-2` |
| 인당단가 | 수강인원 × 이 금액 = 한도 | `20000` |
| 신청시작일 | 안내용 (검증에는 사용하지 않음) | `2026-09-01` |
| 신청마감일 | 안내용 | `2026-09-30` |
| 접수상태 | `접수` 또는 `마감` | `접수` |
| 담당자연락처 | 내부 참고용 (교사에게 노출되지 않음) | `041-640-7221` |
| 보관폴더ID | 새 학기 시작 시 사본 저장 위치 (Google Drive 폴더 ID) | |
| 안내문구 | 추가 안내가 필요할 때 (선택) | |

> **접수상태를 `접수`로 설정해야 교사가 신청할 수 있습니다.**
> 설정을 변경하면 캐시(5분) 만료 후 반영됩니다.

### 1-2. 강좌목록 붙여넣기

`강좌목록` 시트의 2행부터 데이터를 붙여넣습니다.

**붙여넣기 전 확인사항:**

- **헤더 행(1행)을 지우지 마세요.** 코드가 헤더로 열을 찾습니다.
- **수강인원 열에 `#N/A`가 없는지** 확인하세요. `#N/A`가 있으면 해당 강좌는 교사가 선택할 수 없고 "수강인원 데이터 오류" 메시지가 표시됩니다.
- **강좌코드가 중복되지 않는지** 확인하세요. 같은 강좌코드가 두 행 이상 있으면 첫 번째만 인식됩니다.
- **교사 연락처**가 빠짐없이 입력되어 있는지 확인하세요. 연락처가 없으면 뒤 4자리 인증이 불가합니다.

### 1-3. 동작 확인

스프레드시트 메뉴 `📊 운영비 관리` → `설정 확인`을 실행하여 설정값이 정상인지 확인합니다.

## 2. 접수 기간 중

### 2-1. 교사 안내

신청 링크를 교사에게 안내합니다. **URL은 학기가 바뀌어도 변경되지 않습니다.**

교사에게 전달할 사항:
- 온라인 제출 후 **PDF를 공문으로도 별도 제출**해야 접수 처리됨
- `manual/교사용.html`을 인쇄 배포하거나 링크로 안내

### 2-2. 미제출 독촉

메뉴 → `미제출 목록 생성`을 실행하면 `미제출` 시트가 생성됩니다.

두 구역으로 나뉩니다:

| 구역 | 의미 |
|---|---|
| **미제출** | 온라인 신청 자체가 없는 강좌 |
| **공문 미접수** | 온라인 제출은 됐으나 공문이 도착하지 않은 건 |

각 행에 교사 연락처가 포함되어 있으므로 바로 독촉 연락에 사용할 수 있습니다.

### 2-3. 공문 도착 시 접수상태 변경

공문이 도착하면 `신청내역` 시트에서 해당 강좌의 **접수상태** 열을 드롭다운에서 `접수`로 변경합니다.

| 상태 | 의미 |
|---|---|
| `미접수` | 온라인 제출 완료, 공문 미도착 |
| `접수` | 온라인 + 공문 모두 완료 → **집계표에 포함됨** |
| `보류` | 확인이 필요한 건 |

> **접수상태를 자유 입력하지 마세요.** 드롭다운(미접수/접수/보류) 외의 값이 들어가면 집계에서 누락됩니다.

## 3. 마감 후

### 3-1. 신청 마감

`설정` 시트의 `접수상태`를 **`마감`**으로 변경합니다.

교사가 접속하면 "신청이 마감되었습니다" 화면이 표시됩니다.

### 3-2. 집계표 생성

메뉴 → `집계표 새로고침`을 실행합니다.

- **접수상태가 `접수`인 건만** 집계에 포함됩니다.
- 집계표는 공문 첨부용 서식이므로 그대로 인쇄하여 사용합니다.
- 하단에 총합계가 자동 계산됩니다.

> 집계표는 몇 번이든 다시 생성할 수 있습니다. 기존 시트를 삭제하고 새로 만듭니다.

---

## 4. 학기 종료 — 새 학기 시작

메뉴 → `새 학기 시작`을 실행합니다.

**실행 순서 (자동 처리):**

1. 현재 신청 건수를 보여주고 진행 여부를 확인합니다.
2. 현재 스프레드시트의 사본을 `[보관] {학기코드} 수업운영비` 이름으로 보관폴더에 저장합니다.
3. 사본이 정상인지 검증합니다. **실패하면 데이터를 삭제하지 않고 중단합니다.**
4. 신청내역·집계표·미제출 시트를 초기화합니다.
5. 강좌목록 2행 이하를 삭제합니다.
6. 접수번호 시퀀스를 초기화합니다.

**실행 후 해야 할 일:**

- `설정` 시트의 학기명·학기코드·신청기간을 새 학기에 맞게 수정
- `설정` 시트의 접수상태를 `접수`로 변경
- `강좌목록` 시트에 새 학기 강좌 데이터 붙여넣기

## 5. 문제 상황 대응

### 웹앱이 응답하지 않을 때

1. GAS 편집기(script.google.com)에서 스크립트가 정상인지 확인
2. 배포 상태 확인: `배포 관리` → 활성 배포가 있는지 확인
3. `clasp push` 후 **기존 배포 편집 → 버전: 새 버전**으로 재배포
4. 그래도 안 되면 Apps Script 실행 로그에서 오류 확인

> **절대 `새 배포`를 하지 마세요.** URL이 바뀌어 교사 안내 링크가 모두 무효화됩니다.

### 강좌 정보가 틀렸을 때

- `강좌목록` 시트에서 직접 수정합니다.
- 수정 후 교사에게 다시 접속하여 제출하도록 안내합니다.
- 이미 제출된 신청은 **재제출해야** 변경된 정보가 반영됩니다.

### 교사가 인증에 실패할 때

- 강좌목록의 교사 연락처를 확인합니다.
- 5회 실패하면 10분간 잠기므로 시간이 지난 후 재시도하도록 안내합니다.
- 연락처가 잘못되어 있으면 강좌목록에서 수정하면 됩니다.

### 동일 강좌에서 중복 제출이 의심될 때

- 중복은 **구조적으로 불가능**합니다. 같은 강좌코드로 재제출하면 기존 행을 덮어씁니다.
- `신청내역` 시트의 `수정횟수` 열에서 재제출 횟수를 확인할 수 있습니다.
